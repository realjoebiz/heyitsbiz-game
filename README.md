# Color Blocks — game.heyitsbiz.com

12×20 colour-matching puzzle. Tap groups of 2+ adjacent blocks (same colour, orthogonal). Cleared blocks fall down, then columns shift left. Win by clearing the grid; lose when no valid moves remain.

- **Live:** https://game.heyitsbiz.com
- **Also in:** BIZ-PC desktop (`Color Blocks` icon)
- **Git:** `realjoebiz/heyitsbiz-game`
- **Stack:** Next.js 14, Tailwind, Coolify/Nixpacks

## Dev

```bash
npm install
npm run dev
```
